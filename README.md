# 📰 NewsExplorer

**Search. Save. Stay informed.**  
NewsExplorer is a responsive web application that allows users to search for the latest news on any topic, explore curated content, and save articles to their personal account.



## 🚀 Live Demo  
🔗 [Visit the App](https://websitecoderr.github.io/newsexplorer/)  








## ✨ Features

- 🔍 **Search by Topic** – Real-time results powered by external news APIs  
- 📝 **Save Articles** – Logged-in users can bookmark stories for later  
- 🔐 **Authentication** – Secure sign-in/out with conditionally rendered UI  
- 📱 **Responsive Design** – Optimized layout for mobile and desktop views  
- 🧭 **Dynamic Navigation** – Context-aware styling and route handling  
- 📊 **User Insights** – In-app feedback and interaction tracking (future scope)

---

## 💡 Usage Guide

1. Enter a keyword into the search bar to explore news stories  
2. Sign up or log in to save articles to your account  
3. Navigate to **Saved Articles** for quick access to personal content  
4. Log out securely via the profile menu
